MindShiftGo Uploader: Privacy Policy and Terms of Use

Last updated: October 30, 2026

MindShiftGo Uploader is a private tool used only by the owner of the YouTube channel @MindShiftGo to upload and schedule the channel's own videos through the YouTube Data API. It is not offered to the public and has no other users.

By using this tool, the user agrees to be bound by the YouTube Terms of Service.

Data accessed

Through Google OAuth and only with the channel owner's consent, the tool accesses permission to upload videos to the owner's YouTube channel, and basic read-only information about that channel and its videos, such as channel name, video title and video status.

How data is used

This data is used only to upload the owner's own videos, set their title, description, tags and publishing time, and confirm that uploads succeeded.

Data storage and sharing

The access token is stored only on the owner's own computer. No user data is sold or shared with any third party, and this tool stores no data on external servers. Data is kept only as long as needed for the purposes above and can be deleted at any time. Any deletion request is completed within 7 calendar days.

Google services

This tool uses YouTube API Services. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page.
